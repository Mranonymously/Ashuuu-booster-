# ASHUUUGAME BOOSTERS

A native Android gaming companion built with Kotlin and Jetpack Compose.

## Features

- Installed launchable-app library with search and one-tap launch.
- Balanced, Performance and Battery Saver in-app profiles.
- Gaming session timer.
- Available-memory and battery-temperature readings.
- Dark premium gaming interface.
- Offline-first: no internet permission, analytics SDK, account system or ads.
- No root access.

## Important technical limits

The profile choices are informational app-side presets. A normal third-party Android app cannot guarantee higher FPS, force GPU/CPU clocks, clear other apps' private memory, disable thermal throttling, or change vendor game-driver behavior. Android and the device manufacturer control those functions. The memory and battery readings are snapshots, not performance benchmarks.

## Requirements

- Android Studio (current stable recommended)
- JDK 17
- Android SDK Platform 35
- Gradle 8.9 or compatible wrapper generated by Android Studio

## Open and build

1. Extract the project ZIP.
2. Open the `ASHUUUGAME_BOOSTERS` folder in Android Studio.
3. Allow Gradle sync to download dependencies.
4. Install an Android 8.0+ device or create an emulator.
5. Press **Run**.

To build a debug APK from the project root:

```bash
gradle assembleDebug
```

APK output:

```text
app/build/outputs/apk/debug/app-debug.apk
```

For a release APK:

```bash
gradle assembleRelease
```

Configure a private signing key in Android Studio or your CI secret store before distributing a release build. Never commit signing keys or passwords to source control.

## Security and privacy

- No network permission is declared.
- No credentials or personal data are requested.
- App discovery uses Android package visibility for launchable apps.
- The app does not access another app's private files or process memory.
- No root, accessibility-service or device-admin privileges are requested.
- Backup is disabled for the application.
- Release builds enable R8 minification.

## Package identity

`com.ashuugameboosters`

Change the namespace and application ID consistently before publishing under a different identity.


## Free cloud APK build with GitHub Actions

This repository includes `.github/workflows/build-apk.yml`.

1. Create a GitHub repository and upload/push the contents of this project.
2. Open the repository's **Actions** tab.
3. Select **Build Android APK** and choose **Run workflow** (or push to `main`/`master`).
4. Open the completed workflow run.
5. Download the `ASHUUUGAME-BOOSTERS-debug-apk` artifact.
6. Extract the artifact ZIP; it contains `app-debug.apk`. Transfer it to your Android phone and install it. You may need to allow installation from that file manager.

The workflow creates a debug APK for testing. A Play Store release should be built as a signed release using a private signing key stored securely in GitHub Actions secrets.
